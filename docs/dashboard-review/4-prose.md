## Recommendation

1. Fix scope and status first. Remove the derived Plug-in hybrid numbers from the shared workbook warning. Resolve the computed summaries, comparison columns and converted map measures against the as-reported rule before claiming workbook fidelity. Add explicit “Model output” labels. Keep “owner-review draft”, “provisional” and “electricity not counted” visible where they matter. Correct the map emissions caveat, the Model scenario labels and the underspecified Hybrid sizing feasibility labels at the same time.
2. Cut the page openers that repeat controls, the Overview cross-menu explanation and the duplicated source/count/download captions. Replace the Hybrid sizing conclusion headings with chart subjects. Keep a short definition for elasticity, storage efficiency, map colour and provisional status wherever readers need it to interpret a chart.
3. Align controls, captions, chart titles, hovers and table headers in the same pass. Preserve the supplied labels, units, filenames and values. Give the owner any proposals that touch inline report prose or interpretation as drafts for review.

Rules for future dashboard text:

- Name the quantity first. Use a sentence only when it explains the data, an assumption, a status or how to recover from an empty state.
- Put units on the axis or column and on isolated values and hovers. Identify indices, counts and dimensionless factors by what they count or scale.
- Use the shared cycle and powertrain names. Identify generated traces and the source of each displayed figure.
- Explain a symbol or abbreviation once, near the chart. Use the same words for its legend, tooltip and table.
- Prefer one short sentence per idea. Cut copy that repeats the heading, the controls or an adjacent warning.
- Use measured or saved results for data-dependent text. Keep conclusions and interpretation in the owner's draft.
